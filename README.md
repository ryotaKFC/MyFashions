# My Fashion

# 概要
- 学内イベントの初心者限定ハッカソンである「ビギナーズハッカソン」にて制作
- スマホ向けwebアプリ
- 自分のコーデをデータベースでまとめてくれる

# 機能
- **コーデのアップロード**
    1. 出かける前にカメラで今日のコーデを撮る
    2. コーデの画像とともに、その日の天気、気温、湿度、ジャンルなどを含めてデータベースへ保存
- **過去に着たコーデの表示**
    - カレンダーやリスト形式で過去に着たコーデが分かる
    - フィルターで温度や天気でコーデを絞り込むこともできる
- **お気に入り登録機能**
    - お気に入りのコーデを設定できる
    - コーデを表示する際、お気に入りのコーデが優先的に表示される
 
# 使用技術
- Laravel

# 展望 
- **今日のおすすめのコーデ機能**
  - 今日のおすすめボタンをおすだけで、今日の天気や季節などを考慮して、おすすめのコーデを提案
- **コーデアップロード時の情報自動入力**
  - コーデアップロード時に、その日の天気。気温、湿度、ジャンルetc... をAPIやAIを活用して自動的に入力したい
